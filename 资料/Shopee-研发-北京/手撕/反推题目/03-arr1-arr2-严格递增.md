# 替换数组元素使其严格递增

> **来源状态：**根据用户提供的 Shopee 题目截图整理；按截图转录，原始在线考试页面未单独核验。

## 题目

Shopee 算法团队进行团建游戏，规则如下：

给定两个整数数组 `arr1` 和 `arr2`。在每一步操作中，可以分别从 `arr1` 和 `arr2` 中选择下标 `i` 和 `j`，满足 `0 <= i <= j` 且下标分别在对应数组范围内，然后执行赋值：

```text
arr1[i] = arr2[j]
```

求使 `arr1` 严格递增所需的最少操作次数。如果无法使 `arr1` 严格递增，返回 `-1`。如果 `arr1` 初始时已经严格递增，最少操作次数可以为 `0`。

## 示例 1

```text
输入：arr1 = [1,5,3,6,7], arr2 = [1,3,2,4]
输出：1
解释：用 2 替换 5，之后 arr1 = [1,2,3,6,7]。
```

## 示例 2

```text
输入：arr1 = [1,5,3,6,7], arr2 = [1,6,3,3]
输出：-1
解释：无法使 arr1 严格递增。
```

## 条件

- `1 <= arr1.length, arr2.length <= 100`
- `0 <= arr1[i], arr2[i] <= 10^6`
- 时间限制：3000 ms
- 内存限制：256 MB

## 题面备注

截图中的下标条件可读作 `0 <= i <= j`，并要求 `i`、`j` 分别是 `arr1`、`arr2` 的有效下标。该限制按示例 1 中用 `arr2[2]` 替换 `arr1[1]` 整理。
