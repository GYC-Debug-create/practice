## 三、全栈和 Java 方向的题目清单

**N6（全栈技术面，10-09 面）**：AI 生成的代码怎么验证正确性；除了测前端交互和后端接口还有什么验证方式；AI 编码前会不会先检查设计；有没有用 Skills 等工具减少幻觉；AI 改了功能、单测也过了怎么确认可信；单测失败怎么处理；模板方法模式，还了解哪些设计模式；策略模式的业务场景；一亿条流水查最近一天怎么优化；除了索引、覆盖索引、分区分表还有什么思路；先更新库再删缓存能否保证最终一致；延迟双删的流程；密码和身份证号怎么存储；加盐哈希后登录怎么校验；身份证号和密码能用同一方案吗；搜索框 ja / java 响应乱序怎么保证显示 java 的结果；怎么取消未完成的请求；除了取消请求还有什么办法；大日志怎么快速看最新一段；怎么实时看新增日志；已知 requestId 怎么筛日志；JDK 8 默认 GC；final 的作用；final 修饰集合还能增删吗；final 修饰引用还能改属性吗；用过哪些 AI Coding 工具；Agent、深度学习、RAG 了解多少；GIL；装饰器；生成器和迭代器的区别；反问。

**N5（全栈一面，10-18 面）**：1～17 拷打实习和个人项目（原文没有列内容）；接口和抽象类的区别及用法；try-with-resources 还有泄漏风险吗；`close()` 抛异常怎么办；多个资源的关闭顺序；synchronized 是什么；ReentrantLock 和 CAS 的区别；synchronized 怎么声明；单例 Bean 的成员变量存 userId 有什么问题；怎么避免；怎么理解单例 Bean 和容器；容器和 Bean 存在哪里；IoC 和 DI 分别是什么；两者的关系；Bean 的实例化和属性填充；Vue 是什么；父组件怎么把人数传给子组件；实体里有前端不显示的字段有没有安全风险；如果是 password 呢；VO 怎么处理敏感字段；定时任务每 5 分钟执行、有时 8 分钟才执行，怎么避免重复和漏处理；XXL-JOB 多实例怎么避免重复；常见设计模式和例子；反问。

**N4（全栈一面，10-26 面，挂）**：自我介绍；项目做的什么；有没有文档切片，怎么设计；SDD 大致流程；HashMap 用用户对象作 key，中途改了字段会怎样；换你会怎么设计；用过 MySQL 吗；为什么用 B+ 树不用 B 树；聚簇和非聚簇索引；联合索引；ABC 联合索引查 B、C 能查出来吗；Spring 怎么管理事务；了解 `@Transactional` 吗；同类中用 `this` 调用 `@Transactional` 方法，代理会生效吗；Spring 注入 Bean 有哪些方式；了解 SQL 注入吗；MyBatis 里 `$` 和 `#` 的区别；创建线程的方式；Runnable 和 Callable 的区别；Linux 怎么看 CPU 和内存；用户上传文章到页面回显摘要的过程；前端调 GET 接口获取用户信息并回显的过程；订单创建成功但通知失败，要回滚吗。作者自述挂在「知识都是通用八股，稍微偏一点就不会」。
