# 卓望 · 真人技术面题目提炼（2026-10-26）

> 来源：网络公开面经（牛客、小红书），27 届秋招，2026 年 10 月。题目已按知识点重新归类、改写，不是原文。
> **AI 面过了再用。** AI 面的准备看 `AI面试准备-1026.md`。

## 一、几场面试长什么样

| 场次 | 岗位 | 轮次 | 结构 |
|---|---|---|---|
| ① | 全栈开发 | 技术面，两位面试官（10 月上旬） | 自我介绍 → **AI Coding 深挖（8 问）** → 设计模式 → MySQL 大数据量 → Redis 一致性 → 敏感数据存储 → 前端异步请求 → Linux 日志 → Java 基础 → AI 基础和 Python → 反问。作者说 AI Coding「追问得比较细」 |
| ② | 全栈开发 | 一面（10 月中旬），没写是不是 AI 面 | **前 17 问都是实习和项目拷打**，然后是 Java、Spring、Vue、安全、定时任务、设计模式，一共约 40 问 |
| ③ | 安全开发 | 一面，23 分钟，没写是不是 AI 面 | 全是八股，有一题追问「代码怎么写」 |
| ④ | 未写 | 未写 | 只有一句话：只问八股不问项目，十分钟结束 |

**和 AI 面的区别**：AI 面是广度问答，每题追问一层；真人面会**挖项目和 AI Coding**，同一个知识点**连环追问 2～4 层**（例如：final 的作用 → final 修饰的集合能不能增删 → final 修饰的引用能不能改属性）。

## 二、按知识点归类

箭头表示同一题的追问链。

### AI Coding（场次 ①，问得最细）
- 你的项目是不是基本都用 AI Coding 完成的
- AI 生成的代码怎么验证正确性 → 除了测前端交互和后端接口，还有别的验证方式吗
- AI 开始编码之前，你会不会检查它给的技术设计是否合理
- 有没有用 Skills 或其他工具减少 AI 的幻觉和错误
- AI 改了一个功能，说代码和单测都通过了，你怎么进一步确认结果可信
- AI 改完代码后单测反而失败了，你怎么处理
- 用过哪些 AI Coding 工具；Agent、深度学习、RAG 了解多少

### 项目和实习（场次 ②，17 问，没列具体题）
- 实习和个人项目拷打

### 设计模式
- 项目里用了模板方法模式，除此之外还了解哪些设计模式
- 举一个适合用策略模式的实际业务场景
- 常见设计模式有哪些，各举实际例子

### MySQL
- 流水表 1 亿条数据，只查最近一天，从哪些方面优化 → 除了索引、覆盖索引、分区分表，还有别的思路吗
- 索引为什么会失效
- MySQL 什么情况下会锁表

### Redis
- 先更新数据库再删缓存，能不能保证最终一致 → 延迟双删的具体流程

### 安全
- 密码、身份证号这类敏感信息在数据库里怎么存 → 密码加盐哈希存储后，登录时怎么校验 → 身份证号能不能和密码用同一种方案（提示：身份证要能还原，所以是加密不是哈希）
- 实体类里有前端不显示的字段，有安全风险吗 → 如果这个字段是 password 呢 → 返回数据时 VO 怎么处理敏感字段
- AES 相关内容

### 前端
- 搜索框先输入「ja」发一次请求，再输入「java」又发一次；「java」的响应先回来、「ja」的后回来，怎么保证页面最终显示「java」的结果 → 怎么取消上一次还没完成的请求 → 除了取消，还有什么办法避免旧结果覆盖新结果
- Vue 是什么；父组件怎么把数据传给子组件

### Linux
- 日志文件很大，怎么快速看最新的一部分 → 怎么持续实时查看新增日志 → 已知一个 requestId，怎么筛出这个请求的日志

### Java 基础
- JDK 8 默认用什么垃圾回收器
- final 的作用，为什么需要 final → final 修饰集合后还能增删元素吗 → final 修饰对象引用后还能改对象内部属性吗
- 接口和抽象类的区别，什么时候用哪个
- try-with-resources 读文件还有资源泄漏风险吗 → `close()` 抛异常会怎样 → 多个资源按什么顺序关闭
- 序列化接口要实现什么
- OOM 怎么调优，jstack 怎么用、怎么看输出

### Java 并发
- synchronized 是什么 → ReentrantLock 和 CAS 是什么，有什么区别 → synchronized 具体怎么声明
- Java 线程池有哪几种
- 两个线程都执行完以后，再一起打印一个东西 → 追问代码怎么写（CountDownLatch / CyclicBarrier / CompletableFuture）

### Spring / Spring Boot / MyBatis
- 单例 Bean 用成员变量临时存 userId，会有什么问题 → 怎么避免 → 怎么理解单例 Bean 和 Spring 容器 → 容器和 Bean 存在哪里
- IoC 和 DI 分别是什么，是什么关系 → Bean 的实例化和属性填充是什么
- Spring Boot 的加载顺序；静态资源加载
- Spring Boot 从 Tomcat 换成其他容器，要调整哪些参数
- MyBatis `#` 和 `$` 的区别

### 定时任务
- 每 5 分钟执行一次的任务，有时候 8 分钟才执行，怎么避免重复和漏处理 → XXL-JOB 多实例时怎么避免重复处理

### 接口对接
- 对接过外部接口吗：流程是什么、要注意什么、用什么协议、请求怎么构成、凭证怎么获取、用了哪些参数

### Python（场次 ①）
- GIL 是什么，有什么作用；装饰器；生成器和迭代器的区别
