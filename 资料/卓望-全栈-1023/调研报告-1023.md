## 三、面经

### 最重要的两篇：27 届全栈

**2026-10-09 全栈技术面**（两位面试官）
1. AI 生成的代码怎么验证正确性
2. AI 改了代码、单测也过了，怎么确认真正可信
3. AI 方案实现前会不会先检查设计
4. 怎么用 Skills 或其他工具降低模型幻觉
5. 模板方法模式、策略模式的业务场景
6. 一亿条流水数据怎么查最近一天的记录
7. 先更新数据库再删 Redis 缓存，能不能保证一致
8. 延迟双删的具体过程
9. 密码和身份证为什么不能用同一种存储方式
10. 前端搜索框先发的请求后返回，怎么避免覆盖新结果
11. 怎么取消已经发出的前端请求
12. 大型 Linux 日志里怎么按 requestId 找记录
13. Java `final` 的作用
14. JDK 8 默认垃圾回收器
15. Python GIL、装饰器、生成器、迭代器

**2026-10-18 全栈一面**
- try-with-resources 释放资源，异常时的关闭顺序
- synchronized、ReentrantLock、CAS 的区别
- Spring 单例 Bean 的成员变量存用户 ID 有什么线程安全问题
- IoC 和 DI 的关系
- Vue 父组件怎么给子组件传值
- 为什么不能直接返回带 password 字段的实体
- XXL-JOB 多实例怎么避免任务重复执行
- 每 5 分钟执行的定时任务跑了超过 5 分钟，怎么防重复或漏执行
- 常见设计模式的业务用法
