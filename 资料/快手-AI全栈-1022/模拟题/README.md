# AI Coding 模拟题

两道题，对应目前看到的两种考法。题目是按蚂蚁、美团、Meta 公开出来的题型自己编的，不是快手真题。

| 题 | 考法 | 限时 | 对应 |
|---|---|---|---|
| [模拟 1：评论服务](模拟1-评论服务/README.md) | 改造已有代码，分 4 关 | 60 分钟 | Meta：给多文件小项目，修 bug → 加功能 → 边界 → 扩展 |
| [模拟 2：订单详情页](模拟2-订单详情页/README.md) | 从零做全栈 | 90 分钟 | 美团 / 蚂蚁：给需求文档，交付能跑的前后端 |

**`评分-做完再看/` 里是隐藏测试和评分标准，做完之前别打开。**

## 怎么做

1. **把题目文件夹复制到别处再做**，原题留着可以重做：
   ```powershell
   Copy-Item -Recurse "模拟1-评论服务" "D:\练习\模拟1"
   ```
2. 在复制出来的目录里 `git init`，先提交一次初始状态；之后每过一关、每完成一块提交一次。评估时会看提交记录
3. 准备一个 `过程记录.md`，随手记：几点几分开始做哪块、做了什么决定、AI 哪里写错了、你怎么发现的
4. 开计时器，从读 README 开始算时间。**到点就停**，没做完的写进过程记录
5. 用你面试时打算用的那套工具（IDE + AI 工具），尽量和面试当天的环境一致
6. 边做边说出声，练习给面试官讲：让 AI 做什么、为什么、它写得对不对

## 做完交给我评估

把下面几样东西给我：

- 你的项目目录路径
- `过程记录.md`
- AI 对话记录（Claude Code 用 `/export` 导出；其他工具复制或截图）
- 模拟 2 的前端截图

隐藏测试和验收脚本由我来跑，按评分标准给你出分数、扣分点和改进建议。
