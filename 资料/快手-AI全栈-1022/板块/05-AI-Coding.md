- AI 全栈一面（8.25，已核实）：做一个类似「满 XX 钱获得赠品」的页面 → 题型是交付型小功能，不是算法
- 二面凉经（09-21，未核实）：简短需求 → 自主确定功能 → 实现并测试

- 9.14 二面（岗位待确认，`真题\04`）：「写一个日志排查工具」，作者用自己的 Claude Code

**评审后调整**：练习改成 2 次 30 分钟交付型小功能（如满减赠品页）+ 1 次完整走「装环境 → 做题 → 提交」链路；准备一个备用模型，主模型不可用时能切换。VC CLI 的操作指引以面试邮件为准，**今天先确认装好、绑好**。
