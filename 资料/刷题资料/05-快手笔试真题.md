## 1. 字符串 RLE 压缩

**题意：**把连续相同的字符压缩成"次数 + 字符"，例如 `aaabcc` → `3a1b2c`。

**思路：**双指针。i 指向一段相同字符的开头，j 往后走到第一个不同的字符，j − i 就是次数。

```java
import java.util.*;
public class Main {
    public static void main(String[] args) {
        String s = new Scanner(System.in).nextLine().trim();
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < s.length(); ) {
            int j = i;
            while (j < s.length() && s.charAt(j) == s.charAt(i)) j++;
            sb.append(j - i).append(s.charAt(i));
            i = j;
        }
        System.out.println(sb);
    }
}
```

**坑：**拼字符串要用 StringBuilder，在循环里用 `+=` 会很慢。

## 2. 二进制中 1 的个数

**题意：**给一个 32 位整数（可能是负数），输出它的二进制里有几个 1。

**思路：**`Integer.bitCount(n)`，负数会按补码统计。手写版：`n &= n - 1` 每次消掉最低位的 1。

```java
import java.util.*;
public class Main {
    public static void main(String[] args) {
        int n = new Scanner(System.in).nextInt();
        int cnt = 0;
        while (n != 0) { n &= n - 1; cnt++; }   // 负数也能正确结束
        System.out.println(cnt);
    }
}
```

**坑：**如果用 `n >> 1` 循环，负数右移会一直补 1，变成死循环；要用 `>>>`，或者用上面的写法。

## 3. 最大子数组和（结果为负数时输出 0）

**题意：**输入用逗号分隔的整数，求连续子数组的最大和；如果最大和 ≤ 0 就输出 0。

**思路：**Kadane 算法。cur = 以当前元素结尾的最大和 = max(当前元素, cur + 当前元素)。答案的初始值设成 0，就自动处理了"负数输出 0"。

```java
import java.util.*;
public class Main {
    public static void main(String[] args) {
        String[] p = new Scanner(System.in).nextLine().trim().split(",");
        long best = 0, cur = 0;
        for (String x : p) {
            long v = Long.parseLong(x.trim());
            cur = Math.max(v, cur + v);
            best = Math.max(best, cur);
        }
        System.out.println(best);
    }
}
```

## 4. 只含加减的表达式求值（不能用 eval）

**题意：**输入 `1+2-3`、`-1+2` 这类只有加减的整数表达式，输出结果。

**思路：**一边扫描一边累加数字；遇到 + 或 − 时，把前一个数带着符号加进结果，再记下新的符号。开头的负号也能被同一套逻辑处理。

```java
import java.util.*;
public class Main {
    public static void main(String[] args) {
        String s = new Scanner(System.in).nextLine().trim().replace("\"", "");
        long res = 0, num = 0;
        int sign = 1;
        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) num = num * 10 + (c - '0');
            else if (c == '+' || c == '-') {
                res += sign * num;
                num = 0;
                sign = (c == '+') ? 1 : -1;
            }
        }
        res += sign * num;
        System.out.println(res);
    }
}
```

**坑：**输入可能带引号或空格，先清理掉。如果加上括号，就是 LeetCode 224，要用栈。

## 5. 电话号码字母组合

**题意：**输入只含数字 2–9 的字符串，按手机九宫格输出所有字母组合，字典序升序，格式是 `[ad, ae, ...]`。

**思路：**回溯（DFS）。每一位依次试这个数字对应的每个字母。字母本身按顺序排，所以生成的结果天然是字典序；用 TreeSet 可以同时保证去重和排序。

```java
import java.util.*;
public class Main {
    static String[] MAP = {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};
    static TreeSet<String> res = new TreeSet<>();

    static void dfs(String d, int i, StringBuilder path) {
        if (i == d.length()) { res.add(path.toString()); return; }
        for (char c : MAP[d.charAt(i) - '0'].toCharArray()) {
            path.append(c);
            dfs(d, i + 1, path);
            path.deleteCharAt(path.length() - 1);   // 回溯
        }
    }

    public static void main(String[] args) {
        String d = new Scanner(System.in).nextLine().trim();
        dfs(d, 0, new StringBuilder());
        System.out.println(new ArrayList<>(res));   // 打印格式就是 [ad, ae, ...]
    }
}
```

## 6. 验证 IPv4 / IPv6

**题意：**判断字符串是合法的 IPv4、合法的 IPv6，还是都不是。

**规则：**
- IPv4：4 段十进制数，范围 0–255，用点分隔；**不能有前导 0**（01 不合法，单独的 0 合法）。
- IPv6：8 段，每段 1–4 位十六进制数，大小写都行；**不能有空段**（不允许 `::`），每段不能超过 4 位。

```java
import java.util.*;
public class Main {
    static String check(String s) {
        if (s.chars().filter(c -> c == '.').count() == 3) {
            for (String p : s.split("\\.", -1)) {             // -1：保留末尾的空段
                if (p.isEmpty() || p.length() > 3) return "Neither";
                if (p.length() > 1 && p.charAt(0) == '0') return "Neither";
                for (char c : p.toCharArray()) if (!Character.isDigit(c)) return "Neither";
                if (Integer.parseInt(p) > 255) return "Neither";
            }
            return "IPv4";
        }
        if (s.chars().filter(c -> c == ':').count() == 7) {
            for (String p : s.split(":", -1)) {
                if (p.isEmpty() || p.length() > 4) return "Neither";
                for (char c : p.toCharArray()) if (Character.digit(c, 16) < 0) return "Neither";
            }
            return "IPv6";
        }
        return "Neither";
    }

    public static void main(String[] args) {
        System.out.println(check(new Scanner(System.in).nextLine().trim()));
    }
}
```

**坑：**`split` 一定要带 `-1`，否则 `1.1.1.1.` 末尾的空段会被吞掉，误判为合法。输出的字符串（IPv4 / IPv6 / Neither）**以题目要求为准**。

## 7. 编辑距离

**题意：**两个字符串，每次可以插入、删除或替换一个字符，问最少几步能把第一个变成第二个。

**思路：**`dp[i][j]` = a 的前 i 个字符变成 b 的前 j 个字符的最少步数。
- 如果两个字符相等：`dp[i][j] = dp[i-1][j-1]`
- 如果不相等：`1 + min(替换 dp[i-1][j-1], 删除 dp[i-1][j], 插入 dp[i][j-1])`

```java
import java.util.*;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String a = sc.nextLine(), b = sc.nextLine();
        int m = a.length(), n = b.length();
        int[][] dp = new int[m + 1][n + 1];
        for (int i = 0; i <= m; i++) dp[i][0] = i;
        for (int j = 0; j <= n; j++) dp[0][j] = j;
        for (int i = 1; i <= m; i++)
            for (int j = 1; j <= n; j++)
                dp[i][j] = a.charAt(i - 1) == b.charAt(j - 1)
                        ? dp[i - 1][j - 1]
                        : 1 + Math.min(dp[i - 1][j - 1], Math.min(dp[i - 1][j], dp[i][j - 1]));
        System.out.println(dp[m][n]);
    }
}
```

## 8. x 变成 y 的最少操作次数（+1、−1、×2）

**题意：**输入 `x,y`，每次只能对 x 做 +1、−1 或 ×2，问最少几次能变成 y。

**思路：**求"最少步数"首先想到 **BFS**。每个数是一个节点，三种操作是三条边。要给搜索范围设边界，否则 ×2 会无限增长；本题范围是 −100 到 100，边界取 2 × max(|x|, |y|) + 2 足够。

```java
import java.util.*;
public class Main {
    public static void main(String[] args) {
        String[] p = new Scanner(System.in).nextLine().trim().split(",");
        int x = Integer.parseInt(p[0].trim()), y = Integer.parseInt(p[1].trim());
        int L = 2 * Math.max(Math.abs(x), Math.abs(y)) + 2;   // 搜索范围 [-L, L]
        int[] dist = new int[2 * L + 1];
        Arrays.fill(dist, -1);
        ArrayDeque<Integer> q = new ArrayDeque<>();
        dist[x + L] = 0;
        q.add(x);
        while (!q.isEmpty()) {
            int u = q.poll();
            if (u == y) break;
            for (int v : new int[]{u + 1, u - 1, u * 2}) {
                if (v < -L || v > L || dist[v + L] != -1) continue;
                dist[v + L] = dist[u + L] + 1;
                q.add(v);
            }
        }
        System.out.println(dist[y + L]);
    }
}
```

**验证：**3 → 11 走的是 3 → 6 → 12 → 11，3 步；5 → 8 走的是 5 → 4 → 8，2 步。

## 9. 阶乘末尾第一个非零位（N ≤ 1000 万）

**题意：**求 N! 从右往左第一个不是 0 的数字，例如 6! = 720，答案是 2。

**思路：**末尾的 0 全部来自 2 × 5。累乘时把每个数里的因子 2 和因子 5 都拆出来，分别计数，剩下的部分只保留个位相乘。最后把多出来的那些 2（2 的个数减去 5 的个数）乘回去，再取个位。

```java
import java.util.*;
public class Main {
    public static void main(String[] args) {
        int n = new Scanner(System.in).nextInt();
        long prod = 1, c2 = 0, c5 = 0;
        for (int i = 2; i <= n; i++) {
            int v = i;
            while (v % 2 == 0) { v /= 2; c2++; }
            while (v % 5 == 0) { v /= 5; c5++; }
            prod = prod * (v % 10) % 10;
        }
        for (long k = 0; k < c2 - c5; k++) prod = prod * 2 % 10;
        System.out.println(prod);
    }
}
```

**坑：**直接算阶乘一定会溢出；不拆掉 2 和 5、只保留个位也会出错。0! = 1! = 1。

## 10. 数组分成两半，使两部分的和之差最小

**题意：**把数组分成两组，使 |S1 − S2| 最小，输出这个最小差。

**思路：**等价于从数组里挑一些数，让它们的和尽量接近 sum/2，这就是 **0/1 背包**。`dp[s]` 表示能不能凑出和 s。

```java
import java.util.*;
import java.io.*;
public class Main {
    public static void main(String[] args) throws IOException {
        StreamTokenizer in = new StreamTokenizer(new BufferedInputStream(System.in));
        in.nextToken(); int n = (int) in.nval;
        long[] a = new long[n]; long sum = 0;
        for (int i = 0; i < n; i++) { in.nextToken(); a[i] = (long) in.nval; sum += a[i]; }
        int half = (int) (sum / 2);
        boolean[] dp = new boolean[half + 1];
        dp[0] = true;
        for (long v : a)
            for (int s = half; s >= v; s--)          // 倒序遍历，保证每个数只用一次
                if (dp[s - (int) v]) dp[s] = true;
        int best = half;
        while (!dp[best]) best--;
        System.out.println(sum - 2L * best);
    }
}
```

**说明：**题目给的数据范围很大，这种情况下没有精确的多项式解法。真考到时，先用背包写对、拿到中小数据的分；时间不够的话，退而求其次用贪心（从大到小排序，每个数放进当前和较小的那一组）。

## 11. 最长等差数列（顺序可以打乱）

**题意：**从无序数组里挑出尽量多的数，让它们能排成一个等差数列，输出最大个数。例如 `1 4 2 5 3` → 5。

**思路：**因为顺序可以打乱，先**排序**，问题就变成 LeetCode 1027（最长等差子序列）。`dp[j]` 是一个哈希表，记录"以 a[j] 结尾、公差为 d 的最长长度"。

```java
import java.util.*;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        long[] a = new long[n];
        for (int i = 0; i < n; i++) a[i] = sc.nextLong();
        if (n <= 2) { System.out.println(n); return; }
        Arrays.sort(a);
        @SuppressWarnings("unchecked")
        Map<Long, Integer>[] dp = new HashMap[n];
        int best = 2;
        for (int j = 0; j < n; j++) {
            dp[j] = new HashMap<>();
            for (int i = 0; i < j; i++) {
                long d = a[j] - a[i];
                int len = dp[i].getOrDefault(d, 1) + 1;
                dp[j].put(d, Math.max(dp[j].getOrDefault(d, 0), len));
                best = Math.max(best, len);
            }
        }
        System.out.println(best);
    }
}
```

**复杂度：**O(n²)，n 在几千以内没问题；数据真到千万级时，先保证正确，拿部分分。
