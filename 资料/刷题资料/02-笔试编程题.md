## W-1 两个数组的元素匹配

**来源**：用友全栈笔试笔经（牛客，2026-08-30），按描述改编

**假设**：两个数组按差值配对，每个元素最多用一次，求最多能配几对。

给数组 A（n 个数）、B（m 个数）和整数 k。A 中一个元素和 B 中一个元素能配对，当且仅当两者差的绝对值 ≤ k；每个元素最多参与一次配对。求最多能配成多少对。

- 输入：第一行 `n m k`；第二行 n 个整数；第三行 m 个整数
- 范围：1 ≤ n, m ≤ 1e5；元素在 [-1e9, 1e9]；0 ≤ k ≤ 1e9
- 输出：一个整数

```
输入 1：
3 3 1
1 4 7
2 5 10
输出：2
```

```
输入 2（边界：各一个元素）：
1 1 0
5
5
输出：1
```

```
输入 3（无序）：
4 3 1
10 3 1 2
9 0 3
输出：3
```

## W-2 连续 k 个数都大于 t 的窗口计数

**来源**：用友全栈笔试笔经（牛客，2026-08-30；另见 2026-08-27 A 卷记录），按描述改编

**假设**：窗口可以重叠，每个起点算一个窗口；"大于"是严格大于。

给 n 个整数、窗口长度 k 和阈值 t。统计有多少个长度为 k 的连续子数组，里面每个数都 > t。

- 输入：第一行 `n k t`；第二行 n 个整数
- 范围：1 ≤ n, k ≤ 2e5；元素和 t 在 int 范围内
- 输出：一个整数
- 要求：O(n)，O(nk) 会超时

```
输入 1：
6 2 3
4 5 1 6 7 8
输出：3
```

```
输入 2（边界：k > n）：
3 4 0
1 2 3
输出：0
```

```
输入 3（严格大于）：
5 1 5
5 6 5 7 5
输出：2
```

## W-3 字符串解码（圆括号版，等价 LC394）

**来源**：用友全栈笔试笔经（牛客，2026-08-30），按描述改编

**假设**：数字后面一定跟括号；数字可以是多位数；括号外可以有普通小写字母；输入合法。

编码规则 `k(s)` 表示 s 重复 k 次，可以嵌套。给一个编码后的字符串，输出解码结果。

- 输入：一行字符串，长度 ≤ 1000，解码后长度 ≤ 1e5
- 输出：解码后的字符串

```
输入 1：3(a2(bc))
输出：abcbcabcbcabcbc
```

```
输入 2（多位数）：2(ab)c10(d)
输出：ababcdddddddddd
```

```
输入 3（边界：没有括号）：xyz
输出：xyz
```

## W-4 防御塔：起点能否到终点

**来源**：用友全栈笔试笔经（牛客，2026-08-30），按描述改编

**假设**：地图是网格；塔的范围是圆形，范围内的格子不能走；上下左右四个方向移动。
（如果真题是平面上的圆，或者塔的范围是可走区域，核心还是 BFS，或者"两圆相交就连通"的并查集。）

R 行 C 列的网格，有 n 座塔，第 i 座塔中心在 (x, y)，半径 r。格子 (i, j) 满足 (i-x)² + (j-y)² ≤ r² 就被覆盖、不能走。问能否从 (sx, sy) 走到 (tx, ty)。起点或终点被覆盖，直接输出 NO。

- 输入：第一行 `R C n`；接下来 n 行，每行 `x y r`；最后一行 `sx sy tx ty`。坐标从 0 开始
- 范围：1 ≤ R, C ≤ 500；0 ≤ n ≤ 50；0 ≤ r ≤ 50
- 输出：`YES` 或 `NO`

```
输入 1：
3 3 1
1 1 0
0 0 2 2
输出：YES
```

```
输入 2（起点被围住）：
3 3 1
1 1 1
0 0 2 2
输出：NO
```

```
输入 3（边界：没有塔，起点就是终点）：
1 1 0
0 0 0 0
输出：YES
```

## W-5 JSON 日期区间合并

**来源**：用友软件开发岗笔试笔经（牛客，2026-09-21 发帖，0919 场；另见 2026-09-20），按描述改编

**假设**：日期都是 `yyyy-MM-dd`，可以直接按字符串比较大小；闭区间；重叠或端点相同才合并，相邻的两天不合并；对象里 start、end 顺序不固定；JSON 可能跨多行、有多余空格。**不能用 JSON 库，自己解析。**

输入一个 JSON 数组，每个元素是 `{"start":"日期","end":"日期"}`。合并重叠区间，按 start 升序输出，格式和输入相同、不带空格。

- 输入：一个 JSON 数组（读完全部输入再处理）
- 输出：一行 JSON 数组

```
输入 1：
[{"start":"2024-01-01","end":"2024-01-05"},{"start":"2024-01-03","end":"2024-01-10"}]
输出：
[{"start":"2024-01-01","end":"2024-01-10"}]
```

```
输入 2（键顺序反、无序、端点相同）：
[{"end":"2024-03-02","start":"2024-03-01"}, {"start":"2024-01-01","end":"2024-01-31"},{"start":"2024-01-31", "end":"2024-02-01"}]
输出：
[{"start":"2024-01-01","end":"2024-02-01"},{"start":"2024-03-01","end":"2024-03-02"}]
```

```
输入 3（边界：空数组）：
[]
输出：
[]
```

## W-6 有向图拓扑序（字典序最小）

**来源**：用友软件开发岗笔试笔经（牛客，2026-09-21 发帖，0919 场），按描述改编

**假设**：考的是拓扑排序和判环。

n 个点（编号 1~n）、m 条有向边。输出一个拓扑序；有多个时输出字典序最小的；有环输出 -1。

- 输入：第一行 `n m`；接下来 m 行，每行 `u v` 表示 u → v；可能有重边
- 范围：1 ≤ n ≤ 1e5；0 ≤ m ≤ 2e5
- 输出：一行，空格分隔；或 `-1`

```
输入 1：
4 3
3 1
3 2
4 2
输出：3 1 4 2
```

```
输入 2（有环）：
3 3
1 2
2 3
3 1
输出：-1
```

```
输入 3（边界：没有边）：
3 0
输出：1 2 3
```

## W-7 和不超过目标值的连续子数组个数

**来源**：用友笔试笔经（牛客，2026-09-20），按描述改编

**假设**：所有元素都是正整数（所以能用滑动窗口）。

给 n 个正整数和目标值 target，统计和 ≤ target 的连续子数组个数。

- 输入：第一行 `n target`；第二行 n 个正整数
- 范围：1 ≤ n ≤ 1e5；1 ≤ 元素 ≤ 2e9；0 ≤ target ≤ 1e14
- 输出：一个整数（可能超过 int）
- 要求：O(n)

```
输入 1：
4 5
1 2 3 4
输出：6
```

```
输入 2（边界：target 比任何元素都小）：
1 0
5
输出：0
```

```
输入 3（需要 long）：
2 3000000000
2000000000 2000000000
输出：2
```

追问：如果元素可以是负数，还能用滑动窗口吗？
