## 12. 贪心：最多交换一次，得到最大的数

**题意：**输入一个非负整数，最多交换其中两位数字一次，输出能得到的最大数。例：2736 → 7236。

**思路：**想让数尽量大，就要让**高位尽量大**。从左往右看每一位，找它右边比它大的数字里**最大的那个**；如果最大的数字出现了好几次，选**最靠右的**一个来交换（这样换下去的小数字落在最低的位置）。先记下每个数字最后出现的位置，就能快速判断。

```java
import java.util.*;
public class Main {
    public static void main(String[] args) {
        char[] s = new Scanner(System.in).next().toCharArray();
        int[] last = new int[10];
        for (int i = 0; i < s.length; i++) last[s[i] - '0'] = i;
        outer:
        for (int i = 0; i < s.length; i++) {
            for (int d = 9; d > s[i] - '0'; d--) {
                if (last[d] > i) {                         // 右边有更大的数字
                    char t = s[i]; s[i] = s[last[d]]; s[last[d]] = t;
                    break outer;                           // 只能换一次
                }
            }
        }
        System.out.println(new String(s));
    }
}
```

**复杂度：**O(10n)。**同类题：**数字重新排列，求最大或最小，一般都是"高位优先"的贪心。

## 13. 贪心：删掉 k 位，使剩下的数最小（字典序最小）

**题意：**第一行是一个数字字符串，第二行是 k。删掉其中 k 位，输出剩下能组成的最小数，去掉前导 0，全删光就输出 0。例：1432219 删 3 位 → 1219。

**思路：单调栈。**从左往右扫，如果当前数字比栈顶小，说明把栈顶删掉能让高位变小，就不断弹出（每弹一次用掉一次删除机会）。扫完如果 k 还没用完，就从末尾删。

**"构造字典序最小的字符串"基本都是这个套路：**前面的位置能放更小的字符，就把前面更大的那个删掉。

```java
import java.util.*;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String num = sc.next();
        int k = sc.nextInt();
        StringBuilder st = new StringBuilder();
        for (char c : num.toCharArray()) {
            while (k > 0 && st.length() > 0 && st.charAt(st.length() - 1) > c) {
                st.deleteCharAt(st.length() - 1);
                k--;
            }
            st.append(c);
        }
        st.setLength(st.length() - k);                 // 没删够的从末尾删
        int i = 0;
        while (i < st.length() - 1 && st.charAt(i) == '0') i++;   // 去前导 0
        String res = st.substring(i);
        System.out.println(res.isEmpty() ? "0" : res);
    }
}
```

**复杂度：**O(n)，每个字符最多进栈、出栈各一次。

## 14. 组合数 + 快速幂 + 逆元（模板，必背）

**题意：**第一行是询问次数 q，接下来 q 行，每行是 n 和 k（n ≤ 10⁶），输出 C(n, k) mod 1 000 000 007。

**为什么需要逆元：**C(n, k) = n! ÷ (k! × (n−k)!)。取模之后**不能直接做除法**，要把"除以 x"换成"乘以 x 的逆元"。模数 p 是质数时，x 的逆元等于 x^(p−2) mod p（费马小定理），用**快速幂**算。

**模板三步：**
1. 预处理阶乘 `f[i] = i! mod p`
2. 用快速幂求 `invf[N] = f[N]^(p−2)`，再倒着推出所有阶乘的逆元：`invf[i−1] = invf[i] × i`
3. 每次询问 O(1)：`C(n,k) = f[n] × invf[k] × invf[n−k]`

```java
import java.util.*;
import java.io.*;
public class Main {
    static final long MOD = 1_000_000_007L;
    static final int N = 1_000_000;
    static long[] f = new long[N + 1], invf = new long[N + 1];

    // 快速幂：a^b mod MOD
    static long pow(long a, long b) {
        long r = 1;
        a %= MOD;
        while (b > 0) {
            if ((b & 1) == 1) r = r * a % MOD;
            a = a * a % MOD;
            b >>= 1;
        }
        return r;
    }

    static long C(int n, int k) {
        if (k < 0 || k > n) return 0;
        return f[n] * invf[k] % MOD * invf[n - k] % MOD;
    }

    public static void main(String[] args) throws IOException {
        f[0] = 1;
        for (int i = 1; i <= N; i++) f[i] = f[i - 1] * i % MOD;
        invf[N] = pow(f[N], MOD - 2);                    // 费马小定理求逆元
        for (int i = N; i > 0; i--) invf[i - 1] = invf[i] * i % MOD;

        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int q = Integer.parseInt(br.readLine().trim());
        StringBuilder sb = new StringBuilder();
        while (q-- > 0) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int n = Integer.parseInt(st.nextToken()), k = Integer.parseInt(st.nextToken());
            sb.append(C(n, k)).append('\n');
        }
        System.out.print(sb);
    }
}
```

**坑：**乘法前后都要 `% MOD`，而且要用 long，否则溢出。**常见变形：**隔板法 C(n−1, k−1)、网格路径数 C(m+n, n)、"选若干个满足条件"的计数。

## 15. 区间合并

**题意：**第一行 n，接下来 n 行，每行一个区间 `l r`。合并所有重叠的区间，按起点从小到大，每行输出一个。

**思路：**先**按起点排序**。依次看每个区间：如果它的起点 ≤ 当前合并区间的终点，说明重叠了，就把终点更新为两者中较大的；否则当前区间结束，开始一个新的区间。

```java
import java.util.*;
import java.io.*;
public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine().trim());
        int[][] a = new int[n][2];
        for (int i = 0; i < n; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            a[i][0] = Integer.parseInt(st.nextToken());
            a[i][1] = Integer.parseInt(st.nextToken());
        }
        Arrays.sort(a, (x, y) -> Integer.compare(x[0], y[0]));
        StringBuilder sb = new StringBuilder();
        int l = a[0][0], r = a[0][1];
        for (int i = 1; i < n; i++) {
            if (a[i][0] <= r) r = Math.max(r, a[i][1]);       // 重叠，延长
            else { sb.append(l).append(' ').append(r).append('\n'); l = a[i][0]; r = a[i][1]; }
        }
        sb.append(l).append(' ').append(r).append('\n');
        System.out.print(sb);
    }
}
```

**常见变形：**插入一个新区间（57）、最少移除几个区间才能不重叠（435，按终点排序再贪心）、会议室要几间（253，排序加小顶堆）。

## 16. Dijkstra 单源最短路

**题意：**第一行 `n m s`：n 个点（编号 1..n）、m 条有向边、起点 s。接下来 m 行，每行 `u v w`，表示 u 到 v 有一条权值为 w 的边（w ≥ 0）。输出 s 到每个点的最短距离，用空格分隔，走不到的输出 -1。

**思路：**用**小顶堆**，每次取出当前距离最小、还没确定的点，用它去更新邻居。从堆里取出的距离如果已经过时（比记录的大），就跳过。**前提是边权不能为负**。

```java
import java.util.*;
import java.io.*;
public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken()), m = Integer.parseInt(st.nextToken()), s = Integer.parseInt(st.nextToken());
        List<int[]>[] g = new ArrayList[n + 1];
        for (int i = 1; i <= n; i++) g[i] = new ArrayList<>();
        for (int i = 0; i < m; i++) {
            st = new StringTokenizer(br.readLine());
            int u = Integer.parseInt(st.nextToken()), v = Integer.parseInt(st.nextToken()), w = Integer.parseInt(st.nextToken());
            g[u].add(new int[]{v, w});
        }
        long[] dist = new long[n + 1];
        Arrays.fill(dist, Long.MAX_VALUE);
        dist[s] = 0;
        PriorityQueue<long[]> pq = new PriorityQueue<>((x, y) -> Long.compare(x[0], y[0]));
        pq.add(new long[]{0, s});
        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            int u = (int) cur[1];
            if (cur[0] > dist[u]) continue;                 // 过时的记录，跳过
            for (int[] e : g[u]) {
                if (dist[u] + e[1] < dist[e[0]]) {
                    dist[e[0]] = dist[u] + e[1];
                    pq.add(new long[]{dist[e[0]], e[0]});
                }
            }
        }
        StringBuilder sb = new StringBuilder();
        for (int i = 1; i <= n; i++) sb.append(dist[i] == Long.MAX_VALUE ? -1 : dist[i]).append(i < n ? " " : "\n");
        System.out.print(sb);
    }
}
```

**复杂度：**O((n + m) log m)。**无向图**的话，每条边正反各加一次。**边权都是 1** 时，直接用 BFS 更快。

## 17. 在旋转过的有序数组里查找

**题意：**第一行 n，第二行 n 个**互不相同**的数（一个升序数组在某处被旋转过，比如 4 5 6 7 0 1 2），第三行 target。输出 target 的下标，找不到输出 -1。要求 O(log n)。

**思路：**二分后，`[lo, mid]` 和 `[mid, hi]` 两段里**一定有一段是有序的**。先判断哪段有序，再看 target 在不在这段的范围内，决定往哪边找。

```java
import java.util.*;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = sc.nextInt();
        int t = sc.nextInt();
        int lo = 0, hi = n - 1, ans = -1;
        while (lo <= hi) {
            int mid = (lo + hi) >>> 1;
            if (a[mid] == t) { ans = mid; break; }
            if (a[lo] <= a[mid]) {                             // 左半段有序
                if (a[lo] <= t && t < a[mid]) hi = mid - 1; else lo = mid + 1;
            } else {                                           // 右半段有序
                if (a[mid] < t && t <= a[hi]) lo = mid + 1; else hi = mid - 1;
            }
        }
        System.out.println(ans);
    }
}
```

**常见变形：**找旋转数组的最小值（153）；有重复元素时（81），遇到 `a[lo] == a[mid]` 就 `lo++`。

## 18. 环形数组的最大子数组和

**题意：**第一行 n，第二行 n 个整数，数组首尾相连。求非空子数组的最大和。例：5 -3 5 → 10（5 + 5，跨过了首尾）。

**思路：**最大和只有两种情况：
1. **不跨首尾**：普通的 Kadane（第 3 题）求最大子数组和
2. **跨首尾**：等于"总和减去中间那段**最小**子数组和"

答案取两者较大值。**特例：**如果所有数都是负数，第 2 种情况会得到 0（相当于一个都不选，不合法），这时直接输出第 1 种结果。

```java
import java.util.*;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        long total = 0, curMax = 0, curMin = 0, maxSum = Long.MIN_VALUE, minSum = Long.MAX_VALUE;
        for (int i = 0; i < n; i++) {
            long v = sc.nextLong();
            total += v;
            curMax = Math.max(v, curMax + v); maxSum = Math.max(maxSum, curMax);
            curMin = Math.min(v, curMin + v); minSum = Math.min(minSum, curMin);
        }
        System.out.println(maxSum < 0 ? maxSum : Math.max(maxSum, total - minSum));
    }
}
```

## 19. 树形 DP 入门：相邻节点不能同时选

**题意：**第一行 n（树有 n 个节点，编号 1..n，根是 1），第二行 n 个节点的权值，接下来 n−1 行，每行 `u v` 表示一条边。选出一些节点，**有边相连的两个节点不能同时选**，求选中节点的最大权值和。（类似"打家劫舍 III"和"没有上司的舞会"）

**思路：**每个节点有两种状态：
- `dp[u][1]`：选 u。那么子节点都不能选：`val[u] + Σ dp[v][0]`
- `dp[u][0]`：不选 u。子节点选不选都行，取大的：`Σ max(dp[v][0], dp[v][1])`

答案是 `max(dp[1][0], dp[1][1])`。**要先算完子节点，再算父节点**，所以先用 BFS 求出访问顺序，再**倒序**计算。这样不用递归，节点很多时也不会栈溢出。

```java
import java.util.*;
import java.io.*;
public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine().trim());
        long[] val = new long[n + 1];
        StringTokenizer st = new StringTokenizer(br.readLine());
        for (int i = 1; i <= n; i++) val[i] = Long.parseLong(st.nextToken());
        List<Integer>[] g = new ArrayList[n + 1];
        for (int i = 1; i <= n; i++) g[i] = new ArrayList<>();
        for (int i = 0; i < n - 1; i++) {
            st = new StringTokenizer(br.readLine());
            int u = Integer.parseInt(st.nextToken()), v = Integer.parseInt(st.nextToken());
            g[u].add(v); g[v].add(u);
        }
        int[] order = new int[n], parent = new int[n + 1];
        int head = 0, tail = 0;
        order[tail++] = 1; parent[1] = 0;
        while (head < tail) {                               // BFS 得到从根往下的顺序
            int u = order[head++];
            for (int v : g[u]) if (v != parent[u]) { parent[v] = u; order[tail++] = v; }
        }
        long[][] dp = new long[n + 1][2];
        for (int i = n - 1; i >= 0; i--) {                  // 倒序：先子后父
            int u = order[i];
            dp[u][1] += val[u];
            int p = parent[u];
            if (p != 0) {
                dp[p][0] += Math.max(dp[u][0], dp[u][1]);
                dp[p][1] += dp[u][0];
            }
        }
        System.out.println(Math.max(dp[1][0], dp[1][1]));
    }
}
```

**树形 DP 的套路：**先想清楚每个节点有哪几种状态，再写出**父节点的状态怎么由子节点的状态推出来**。
