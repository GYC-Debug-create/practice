## H-4 有序数列找缺失值

长度为 N-1 的升序数组，元素取自 1…N、互不相同，恰好缺一个，找出缺的那个。先列出三种方法（求和、异或、二分），再写二分。

- 来源：快手面经 G（牛客，音视频方向，**岗位和轮次待确认，日期未写**，收录于 2026-10-18）；面试官原话"先列出所有方法，不要一开始纠结复杂度"
- 输入：第一行 N；第二行 N-1 个升序整数（N=1 时第二行为空）
- 输出：缺失的数

```
输入 1：
5
1 2 4 5
输出：3
```

```
输入 2（缺的是 N）：
3
1 2
输出：3
```

```
输入 3（缺的是 1）：
4
2 3 4
输出：1
```

```
输入 4（边界：N=1）：
1

输出：1
```

- 必问：求和会不会溢出，怎么办；缺的是 1 或 N 时二分对不对；为什么有序数组用二分最好

## H-7 打家劫舍（LC198）· 快手一面实考

相邻的房子不能同时偷，求能偷到的最大金额。实考要求自己写输入。

- 来源：**本人实考**，快手 AI 全栈业务一面，**2026-10-22**
- 输入：第一行 n；第二行 n 个非负整数
- 输出：最大金额

```
输入 1：
4
1 2 3 1
输出：4
```

```
输入 2：
5
2 7 9 3 1
输出：12
```

```
输入 3（边界：只有一家）：
1
5
输出：5
```

- 要点：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`；两个变量滚动，空间 O(1)
- 必问：没有记忆化的递归是 O(2ⁿ)；加记忆化后 O(n)；改成迭代、空间降到 O(1)；递归太深会栈溢出
- 再练一种输入格式：`[2,7,9,3,1]`（读法见 `01-ACM输入输出.md`）

## H-8 打家劫舍 II（LC213，环形）· 快手一面实考追问

房子围成一圈，第一家和最后一家相邻。

- 输入、输出同 H-7

```
输入 1：
3

输出：3
```

```
输入 2：
4
1 2 3 1
输出：4
```

```
输入 3（边界：只有一家）：
1
7
输出：7
```

```
输入 4：
3
1 2 3
输出：3
```

- 要点：**传下标范围**，算 `[0, n-2]` 和 `[1, n-1]` 两次取 max；n=1 直接返回。不需要先判断结果是否同时含首尾
- 易错：`int[]` 切不了就传 `start, end`；或者用 `Arrays.copyOfRange`（左闭右开）

## S-1 场景题：大文件排序（不写代码）

一个大文件里存了一堆无序的数，全部放进内存会 OOM，怎么排序？

- 来源：快手 AI 全栈二面面经（面经 A，笔记日期 **2026-09-07**）
- 要点：**外部排序**。① 按内存大小把文件分块，每块读进内存排好序，写成一个临时文件 ② 多路归并：每个临时文件取一个数放进小顶堆，每次弹出最小值写入结果，再从它所在的文件补一个
- 追问方向：分多少块、每块多大；k 路归并的时间复杂度 O(N log k)；数据有大量重复怎么办（先统计计数）；数据范围有限时可以用计数排序或 bitmap
