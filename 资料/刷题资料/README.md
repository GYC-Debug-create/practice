# 刷题资料

题目、测试数据和练习 prompt。放在 practice 仓库的 `资料\` 目录下，随仓库同步。

## 文件

| 文件 | 内容 |
|---|---|
| `01-ACM输入输出.md` | Java ACM 模板、四种读法、常见坑、IO-1 和 IO-2 两道输入练习 |
| `02-笔试编程题.md` | W-1~W-7：按用友笔经改编的 ACM 题（含测试数据）+ 同题型推荐 + 限时模拟 |
| `03-手撕题.md` | H-1~H-12 + 场景题 S-1：快手面经原题、本人实考、题单补充 |
| `04-练习prompt.md` | 单题陪练、限时模拟、按题型出新题三份 prompt |
| `05-快手笔试真题.md` | K-1~K-11：赛码网快手笔试真题（2019–2020），含讲解和 Java 代码；K-n 就是文件里的第 n 题 |
| `06-高频专题补充.md` | 第 12~19 题：按小红书、亚马逊笔经题型挑的经典题，含讲解和 Java 代码 |

## 来源分类

| 标记 | 含义 |
|---|---|
| **本人实考** | 自己面试时真实考过的题，最优先 |
| **面经原题** | 别人面经里写明的题，标了发帖或面试日期；「未完整核实」表示只读到了摘要 |
| **笔经改编** | 笔经只有一句描述，题面和假设是自己定的，不是原题 |
| **笔试真题** | 平台题库里的历年真题，题意改写过 |
| **同题型经典题** | 按笔经题型挑的 LeetCode 题，不是原题 |
| **自拟题单** | 自己整理的推荐题，不是面经原题 |

## 用法

复制 `04-练习prompt.md` 里的 prompt，在【题目】处粘贴题目全文，发给任意 AI。代码写进 `刷题\java\<题号>\Main.java`，题号去掉横杠。

## 约定

- 改编题都标了「按描述改编」，题面和假设是自己定的，不是原题
- 测试数据是人工计算的；程序结果和预期对不上时，先核对题意和数据
- `05`、`06` 是从 `小红书-质效研发-1018\` 复制过来的，以本目录为准继续维护
- 每次面试或笔试后，把新题补进对应文件，标上来源类型、出处和日期
