目标是能从问题出发解释原理、取舍和边界，并接住递进追问，不以背诵整段答案为目标。

1. 先用宽一些的知识地图定位课程主线和目标；用户还没建立地图时，先带着看地图，不要求先列出陌生术语。
2. 每次只推进一个核心问题。先让用户讲已有理解，再反馈：确认正确部分，指出当前最影响准确性的一个缺口。

4. 不在讲解后立刻要求照原话复述。用新的场景、边界或递进追问检验理解，再继续下一节点。
5. 按当前课程限定范围，不代写练习代码，不编造项目经历。未覆盖的内容明确标记，不算作已掌握。

### 提示后讲清的点

- Java `interface` 与前后端 HTTP API 是不同层次的契约：前者是语言中的类型，可声明多个方法；后者描述系统间的一次请求/响应操作。
- `Object.equals()` 默认按对象身份比较，与 `==` 的引用比较一致；重写 `equals()` 才能定义基于字段的逻辑相等。
- `hashCode()` 是整数哈希结果，不是原始内容；不同对象可能哈希值相同。相等对象必须有相同哈希值，反向不成立。
- HashMap 先按哈希信息定位桶，再用 key 相等性区分映射；逻辑相等的 key 再次 `put` 会更新已有映射的 value。
- Java 源码先由 `javac` 编译为 class 字节码，JVM 执行字节码；部分 JVM 实现会即时编译热点代码为本机指令。
- JVM 是 Java 平台的运行基础，连接 class 文件与操作系统；JDK 提供开发工具。用户要求先从生态位置理解 JVM，再进入运行细节。
