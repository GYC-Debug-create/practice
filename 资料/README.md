## 三、加新资料的规矩

1. **一家公司一个目录**，命名：`公司-岗位-关键日期`（例如 `卓望-全栈-1023`）
2. 每个文件开头写清楚：**出处**（谁搜的 / 哪个平台 / 自己面的）、**日期**、**核实状态**（已核实 / 未核实）
3. 新公司建好目录后，在本文件第一节的表里加一行、第二节加一段
4. 面完一场：复盘写进该公司的 `面试记录\`，真实问到的题补进 `面试题库.md`
5. 不放简历、源码、真实姓名、手机号、邮箱，也不放任何公司的内部信息
